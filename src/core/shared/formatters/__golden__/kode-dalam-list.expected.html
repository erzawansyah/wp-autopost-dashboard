Panduan singkat menyiapkan proyek pengolah data kopi dari nol.

Langkah Instalasi

  1. Instal paket:
npm install kopi-data
npm run build

Pastikan perintah di atas selesai tanpa galat.

  1. Salin berkas konfigurasi bawaan.
  2. Jalankan pemeriksaan awal:
npx kopi-data check --semua
  1. Mulai server lokal.
  • Catatan tambahan:
{ "mode": "lokal" }
  • Ulangi langkah 3 bila konfigurasi berubah.
